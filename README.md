# Painel de Demandas + Quadro de RT

Arquivos do programa e canal de atualizacao automatica.
O app consulta `versao.json`; quando a versao daqui e maior, o Quadro de RT (Win + F) mostra o botao **Atualizar**.

Nenhum dado fica aqui: demandas, clientes e o codigo do quadro compartilhado ficam so nos computadores de quem usa.

Para publicar uma versao nova: altere os arquivos, atualize os hashes e o numero em `versao.json`.
